# sbfnk.github.io

> **Archived.** No longer maintained; last updated June 2022. The site now redirects to https://epiforecasts.io.

Sebastian Funk's former personal academic website, served by GitHub Pages. The repository holds only the static HTML generated by Jekyll; the Jekyll sources are not here. Since June 2021 the front page redirects to https://epiforecasts.io; a few files were updated after that, such as slides added in June 2022.

- `index.html`: the redirect to epiforecasts.io.
- `publications/`, `software/`, `jobs/`, `simulations/`, `snow/`: pages of the old site.
- `pubs/`: PDFs of publications.
- `slides/`: slides from talks, 2017 to 2022.
- `rbi/`: LibBi model files and pages on the `rbi` and `rbi.helpers` R packages.
